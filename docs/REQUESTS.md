# Change requests

Write requests under **Requests** in `docs/CHANGES.md` (or paste the same shape into chat). One batch per message works best.

```
## <short name>
WHERE:    page / window title / element (e.g. "Home > Celestial Flight Board", "left rail > Navigation")
SCHEME:   all | dos | bios | green | amber | paper | pink
WANT:     what it should look or do like (a sentence, hex colours, or "complement of X")
NOT:      what to leave alone (optional)
REF:      screenshot, inspiration image, or "like the Y2K nav"
PRIORITY: now | soon | someday
```

Tips
- Name things by what you see: window titles ("Impact Forecast"), page names (home / weather / sky / post / about).
- Colour: a hex, a scheme name, or a rule ("the complement of that scheme's main colour").
- Screenshots with the spot circled beat a paragraph.
- Say what you like as well as what to change; it stops me undoing it.
- Each round gets an entry in `docs/CHANGES.md` (comes with / added / changed / removed).
