# Void green

Black page, phosphor green only, tinted starfield, optional GLOW (badge in the left rail). 1-bit bitmap art.

**Area:** `themes/void-green`

## Where it lives
- `assets/css/dos-skin.css`  (`phosphor` tokens + the VOID GLOW block)
- `assets/js/starfield.js`
- `assets/js/theme.js`  (glow toggle, `bg()`)
