# DOS blue (default)

The default look: DOS blue page, tan bevelled nav, navy screens, yellow and blue widget pair, soft 4-tone dither art.

**Area:** `themes/dos-blue`

## Where it lives
- `assets/css/dos-skin.css`  (tokens: `:root, :root[data-theme="dos"]`)
- `assets/js/art.js`  (`mode()`: dither; `--art-mid`)

## Start a chat
Paste this into a new chat on the nws repo:

> In nws, area: themes/dos-blue. Read areas/themes/dos-blue/README.md and REQUESTS.md, make the changes, then log the round in docs/CHANGES.md.

Put your requests in `REQUESTS.md` in this folder first (or just type them in the chat).
