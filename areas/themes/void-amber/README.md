# Void amber

Black page, amber only, tinted starfield, optional GLOW. 1-bit bitmap art.

**Area:** `themes/void-amber`

## Where it lives
- `assets/css/dos-skin.css`  (`amber` tokens + the VOID GLOW block)
- `assets/js/starfield.js`
- `assets/js/theme.js`

## Start a chat

> In nws, area: themes/void-amber. Read areas/themes/void-amber/README.md and REQUESTS.md, make the changes, then log the round in docs/CHANGES.md.

Put your requests in `REQUESTS.md` in this folder first (or just type them in the chat).
