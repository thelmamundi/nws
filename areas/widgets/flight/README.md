# Celestial Flight Board

Upcoming exact moments (aspects, sign changes, stations, lunations) with countdowns.

**Area:** `widgets/flight`

## Where it lives
- `assets/js/widgets.js`  (`W.flight`)
- `assets/css/legacy.css`  (instrument styles: `.scr`, `table.board` ...)
- `assets/css/dos-skin.css`  (per-scheme overrides)

## Notes
Shown on: home, weather, sky
