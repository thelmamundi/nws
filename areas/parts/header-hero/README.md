# Page header (hero)

Eyebrow chips, big title, mast chips, intro, and the spinning ASCII planet or glyph (changes with the planetary day on home).

**Area:** `parts/header-hero`

## Where it lives
- `build.js`  (`hero()` macro)
- `assets/js/ascii-art.js`  (planet textures, glyph spin)
- `assets/js/hero-art.js`  (which planet/glyph per page)
- `assets/js/pixel-glyphs.js`
